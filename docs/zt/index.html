Devlog

Can a phone browser draw a real horde?

Zombie Tower started on 22 September as one question: can a phone browser draw a real zombie horde around a single tower? A day later my phone ran 8,000 low-detail zombies at 60 FPS, so I asked the agents for zombies that climb over each other instead of jamming. Version 0.4.7 turned the whole battlefield into a carpet of bodies, and we rolled it back the same day.

From there it grew into a real game: three chapters, ten bosses, cards, a hold-to-charge strike and a 3D world map. This month it wears a Halloween costume. My favourite moment: an agent quietly deleted the "tired garrison" mechanic because a reviewer said nobody noticed it. I noticed. It came back, this time visible.
